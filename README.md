# Guardian Spirit

เว็บไซต์ของเกม **Guardian Spirit** เกมแอ็กชันพิกเซลแนวโซลส์ สู้บอส 4 ตัว ตัวละ 3 ร่าง บอสจำนิสัยการเล่นของคุณแล้วปรับตัวสวนกลับ

- เว็บ: https://karanb2308.github.io/Gurdian-Spirit/
- ดาวน์โหลด: [Releases](https://github.com/KARANb2308/Gurdian-Spirit/releases/latest) (Windows PC `.zip`, Android `.apk`)

## อัปเดตไฟล์เกม

หน้าเว็บลิงก์ไปที่ `releases/latest/download/` ของ repo นี้ อยากปล่อยเวอร์ชันใหม่ให้สร้าง release ใหม่แล้วแนบไฟล์ชื่อเดิม
หน้าเว็บจะชี้ไปไฟล์ใหม่เองโดยไม่ต้องแก้โค้ด:

- `Guardian-Spirit-PC.zip`
- `Guardian-Spirit-Android.apk`
